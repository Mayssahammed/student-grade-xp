# Journal des séances de programmation en binôme

Un tableau à remplir **à chaque séance** de pair programming (itération B). Alterner les rôles
(pilote = écrit le code, copilote = relit, réfléchit, propose).

| Date | Durée | Pilote | Copilote | Objectif de la séance | Cycles TDD réalisés (rouge→vert→refactor) | Difficultés / apprentissages | Commits associés |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## Règle d'alternance
- Changer de rôle toutes les ~15–20 minutes ou à chaque cycle TDD.
- Noter dans le journal qui était pilote et copilote à chaque alternance.
